# 云仓储导航升级与旧项目的关系

本轮由任权伟负责导航与系统集成。改进基于实际本地Isaac Go2工程及云端运行副本实现，后整理进入团队仓库，再同步到本个人项目；并非此前已在本仓库main完成。旧真机入口保留，下面的结果均仅指仿真。

| 项目 | 旧main仿真 | 新云仓储模块 |
|---|---|---|
| 场景与地图 | 手工对应的合成地图，公开入口未端到端复验 | Isaac Sim4.5真实多货架资产，冻结先验/SLAM实验地图与可复现运行记录 |
| 里程计 | 仿真状态真值 | 独立FAST-LIO2与FAST-LIVO2，原生加速度/角速度；真值只离线评价 |
| 全局定位 | 静态map→odom；旧启动脚本无AMCL | 实际运行AMCL，map→odom；唯一估计器适配发布odom→base |
| 障碍处理 | 无本轮仓储实时封路验证 | 实时scan代价层、原生Nav2重规划与行进中物理插入障碍 |
| 运行与验收 | 累积日志与部分人工接口修改 | 单例监督、冻结源码、失联/姿态/净距保护、原始结果和SHA证据 |

AMCL是已知地图上的粒子滤波定位，不等于在线SLAM，也不替代LIO/LIVO的局部连续里程计。当前控制没有使用仿真位置/姿态真值；第三人称展示相机与离线误差评价允许读取仿真状态，不作为算法输入。

FAST-LIO2、FAST-LIVO2、Navfn、DWB和AMCL为第三方算法。本项目贡献是适配、系统集成、调试与验证，不声称原创这些算法。此轮不迁移JetBot、不上真机；长程C按用户决定暂缓。
