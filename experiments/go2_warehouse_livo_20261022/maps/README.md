# 小型复现地图与受控几何

这几份PGM/YAML/JSON为本次实验的辅助CAD先验和配置，不是完整Isaac资产库、SLAM地图或动态障碍真值输入。A/B/C的运行时新增障碍不写入先验；C固定U形侧墙/后墙属于已声明先验。各JSON topology_proposal仅离线连通性提案，实际成功/失败以相邻实验记录为准。

将对应完整目录放到现有云根nav_stage2/maps中；目标已存在时先核对files.sha256，匹配则复用，不覆盖不一致的既有地图。控制/估计运行根仍使用现有环境与外部权重。warehouse_livo_loop_20261022_v2保留历史路线，v3为当前B与高速录像的连续途经点提案，运行时再追加已验证的入口(-2,0)和终点(6,0)；它们，不把其CAD规划长度代替实际行走距离。
